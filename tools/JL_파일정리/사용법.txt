법무법인 제이엘 · 분양공고 분석 파일 자동정리
=================================================

■ 무엇을 하나요
  받으신 파일(제안서 PPT, 검토보고서 PDF, 공문 DOCX, 데이터 JSON, 백업 bundle 등)을
  D드라이브에 단지별 폴더를 만들어 자동으로 넣어 줍니다.

  D:\JL_분양공고분석\
    ├ 번영로_롯데캐슬_센트럴스카이\
    │   ├ 01_공고문원본
    │   ├ 02_분석데이터
    │   ├ 03_검토보고서
    │   ├ 04_제안서_PT
    │   ├ 05_공문_요구서
    │   ├ 06_웹앱
    │   ├ 99_저장소백업
    │   └ 00_기타
    ├ 동탄_파라곤3차_민간임대\
    ├ 광명_힐스테이트11구역\
    │   … (단지별로 계속)
    ├ _미분류\          ← 단지 이름을 못 찾은 파일이 여기로 갑니다
    └ _정리기록.csv     ← 언제 무엇을 어디로 옮겼는지 기록


■ 설치
  1) 이 폴더(JL_파일정리) 전체를 D드라이브 아무 곳에나 두세요.
     예) D:\JL_도구\JL_파일정리\
  2) 끝입니다. 설치할 프로그램은 없습니다.


■ 사용법 — 셋 중 편한 것 하나만 쓰시면 됩니다

  ① 가끔 한 번씩 정리      →  JL_파일정리_실행.bat  더블클릭
     다운로드 폴더에 쌓인 파일을 한 번에 정리합니다.

  ② 작업하는 동안 계속     →  JL_자동감시_시작.bat  더블클릭
     창을 켜 두면 파일이 다운로드되는 즉시 알아서 옮깁니다.
     창을 닫으면 멈춥니다.

  ③ 아예 신경 끄고 싶다    →  윈도우시작시_자동실행_등록.bat
     (마우스 오른쪽 클릭 → 관리자 권한으로 실행)
     컴퓨터를 켤 때마다 감시가 자동으로 켜집니다.
     해제는 자동실행_해제.bat

  ※ 옮기기 전에 결과만 보고 싶으시면 JL_미리보기(옮기지않음).bat


■ 감시하는 폴더
  - 내 다운로드 폴더 (C:\Users\사용자명\Downloads)
  - D:\DDownloads
  두 곳 다 자동으로 확인합니다. 없는 폴더는 그냥 넘어갑니다.


■ 바꾸고 싶을 때

  ▶ 저장 위치를 바꾸려면
     JL_파일정리.ps1 을 메모장으로 열어 7번째 줄쯤의
        [string]$RootDir   = "D:\JL_분양공고분석"
     따옴표 안 경로만 고치세요.

  ▶ 새 단지를 추가하려면
     projects.json 을 메모장으로 열어 아래 형식으로 한 줄 추가하세요.
        { "folder": "새단지_이름", "keywords": ["단지명", "브랜드명", "영문표기"] },
     파일 이름에 keywords 중 하나라도 들어 있으면 그 폴더로 갑니다.
     (띄어쓰기·괄호·밑줄은 무시하고 비교하므로 대충 적으셔도 됩니다)

  ▶ 원본을 지우지 않고 복사만 하려면
     바로가기를 만들어 뒤에 -Copy 를 붙이거나,
     JL_파일정리_실행.bat 안의 명령 끝에 -Copy 를 붙이세요.


■ 안전장치
  - 같은 이름 파일이 있으면 덮어쓰지 않고 뒤에 날짜·시각을 붙입니다.
  - 다운로드가 끝나지 않은 파일(.crdownload, .part, .tmp)은 건드리지 않습니다.
  - 옮긴 내역은 D:\JL_분양공고분석\_정리기록.csv 에 모두 남습니다.


■ 자주 있는 일
  Q. 실행했더니 "이 스크립트를 실행할 수 없습니다"라고 나옵니다.
  A. 반드시 .bat 파일을 더블클릭해 주세요. .ps1 을 직접 실행하면
     윈도우 보안 설정 때문에 막힙니다. .bat 이 우회 옵션을 담고 있습니다.

  Q. 파일이 _미분류로 갔습니다.
  A. 파일 이름에 단지명이 없어서입니다. projects.json 에 키워드를 추가하거나,
     _미분류 폴더에서 직접 옮기시면 됩니다.

  Q. 한글이 깨져 보입니다.
  A. .bat 파일은 그대로 두시고, .ps1 과 .json 은 메모장에서 열 때
     "다른 이름으로 저장 → 인코딩 UTF-8" 을 유지해 주세요.
